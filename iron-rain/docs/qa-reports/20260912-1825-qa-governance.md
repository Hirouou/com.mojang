Commits: `5e7250792601a4760a4c8eca2a3fc2eccd83ed58`, `335d09ceac35fc75da54805990c0d2000bb92af3`.

Correção mínima aplicada:
- adicionado `./modules/crew-station-gate.js` ao shell offline;
- cache atualizado de `v7.12` para `v7.13` para refresh atômico no mesmo URL/PWA.

Commit: `9c5e48e1e0da099e3aa14595d03692aa23e53e27`.
